# Gutfish community code of conduct

## Our standard

We want AgentReady collaboration to be respectful, curious, and technically
rigorous. Examples of welcome behavior include constructive review, clear
evidence, empathy for different experience levels, and graceful correction of
mistakes.

Harassment, discrimination, threats, sexualized attention, doxxing, deliberate
misrepresentation, sustained disruption, and publication of another person's
private information are not acceptable.

## Scope

This code applies in the repository, issue tracker, pull requests, project
spaces, release channels, and public spaces where someone represents AgentReady
or Gutfish.

## Enforcement

Report conduct concerns privately to the project maintainers. Until a dedicated
private conduct address is published, use GitHub private vulnerability reporting
and prefix the title with `CONDUCT:`. Do not put sensitive details in a public
issue.

Maintainers will protect reporter privacy as far as practical, investigate in
good faith, and choose a proportionate response. Responses may include a private
warning, removal of content, temporary restriction, or permanent exclusion.
Maintainers who have a conflict of interest must recuse themselves.

## Attribution

This policy is inspired by the Contributor Covenant and the Rust Code of
Conduct, with wording adapted for this project.
