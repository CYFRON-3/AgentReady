# Public schemas

This directory is reserved for versioned JSON Schemas for:

- AgentReady configuration;
- scan reports;
- rubric definitions or published rubric metadata;
- badge endpoint data, if it differs from the standard Shields schema.

The shapes are intentionally not fabricated in the scaffold. Before adding a
schema, record its identifiers, versioning policy, compatibility rules, and
validation fixtures in an ADR. Runtime types and JSON Schema must be tested for
agreement.
